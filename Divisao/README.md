# Algoritmo de Divisão em Assembly ➗

Aqui encontra-se o projeto focado na construção de operações aritméticas de baixo nível, especificamente o algoritmo de divisão.

## Sobre os arquivos

- **divisao-mikaelle.asm**:
  Este é o código-fonte escrito em Assembly que implementa a lógica de divisão. O algoritmo lida com os registradores, iterando através de deslocamentos (shifts) e subtrações sucessivas (ou método similar) para calcular o quociente e o resto da divisão entre dois números.

- **div-mika.txt** e **memoria-Mikaelle**:
  Estes arquivos contêm os estados de memória e casos de teste utilizados para assegurar que a implementação Assembly se comporta corretamente. Eles detalham as entradas fornecidas na memória e as saídas esperadas após a execução do algoritmo.
