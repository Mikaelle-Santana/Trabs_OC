# Calculadora de 16 Bits 🧮

Este diretório contém o projeto de uma calculadora construída a nível de hardware simulado, utilizando o Logisim ou softwares similares de design de circuitos lógicos.

## O que tem aqui?

- **Mikaelle_Costa_de_Sanatana.circ** e **Mikaelle_Costa_de_Sanatana (16 bits).circ**:
  Estes são os arquivos de simulação do circuito lógico. Eles contêm toda a construção da via de dados (datapath) e da unidade de controle responsáveis por realizar as operações aritméticas e lógicas básicas suportadas por esta calculadora, operando com palavras de 16 bits.

- **CalculadoraOCMikaelle .pdf**:
  Este é o relatório oficial do projeto. Nele, você pode encontrar a documentação completa, as decisões de design de arquitetura, explicações dos componentes criados (como ULA/ALU, registradores, etc) e exemplos de funcionamento da calculadora.

## Como visualizar
Para abrir os arquivos `.circ`, é necessário ter um simulador de circuitos digitais como o **Logisim** instalado na sua máquina.
