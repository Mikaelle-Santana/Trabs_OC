# Trabalhos de Organização de Computadores (OC) 🖥️

Olá! Este repositório contém os meus projetos e atividades desenvolvidos para a disciplina de Organização de Computadores. Todo o código e os circuitos aqui presentes foram desenvolvidos por mim, **Mikaelle Costa de Santana**.

Abaixo, você encontrará uma breve descrição de cada pasta presente neste repositório:

## 🗂️ Estrutura do Repositório

### 1. [Calculadora](./Calculadora/)
Esta pasta contém o projeto de uma calculadora de 16 bits construída do zero. O projeto foi modelado em simulação de circuitos lógicos e acompanhado por um documento de relatório detalhando a sua implementação e funcionamento.

### 2. [Divisão](./Divisao/)
Aqui estão os arquivos relacionados à implementação de um algoritmo de divisão em linguagem Assembly. Estão inclusos o código fonte e os arquivos de teste de memória para validar as operações de divisão e seus respectivos restos.

### 3. [Montador e Swap](./Montador_e_Swap/)
Nesta pasta você encontra o desenvolvimento de um programa "Montador" (Assembler) escrito em Python. O montador tem como objetivo traduzir o código Assembly para linguagem de máquina. Além disso, contém o código de teste "Swap" que realiza a troca de valores na memória, sendo um dos programas utilizados para testar o montador.
